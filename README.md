# Projeto DevOps - Azure & Cloud Computing

Este repositório contém atividades práticas da disciplina de DevOps, desenvolvidas utilizando ambientes em nuvem através da Microsoft Azure e integração com o Visual Studio Code Web.

O objetivo desta etapa é configurar um ambiente de desenvolvimento remoto, compreender a utilização de Workspaces na nuvem e realizar a integração com projetos versionados através do GitHub.

---

## Estrutura do projeto

### Aula01

- Criação e configuração de um Workspace no VS Code Web integrado à Microsoft Azure;
- Preparação do ambiente de desenvolvimento em nuvem;
- Clonagem de projetos disponibilizados pelo professor através de repositórios Git;
- Organização dos projetos dentro do ambiente Azure;
- Visualização e utilização de imagens relacionadas aos serviços utilizados na arquitetura dos projetos.

---

## Tecnologias utilizadas

- Microsoft Azure
- Visual Studio Code Web
- Git
- GitHub
- Terminal Linux/Bash
- Ambiente de desenvolvimento em nuvem

---

## Objetivo do projeto

Praticar conceitos iniciais de DevOps utilizando ambientes cloud, consolidando conhecimentos em:

- Configuração de ambientes de desenvolvimento remoto;
- Utilização de ferramentas integradas à nuvem;
- Versionamento de código com Git;
- Clonagem e organização de repositórios;
- Preparação de infraestrutura para execução de projetos.
